# Legacy Docker Version

This folder preserves the older Docker-based community setup for Cencurity.

Included here are only the public files needed to understand or run that older layout:

- `.env.example`
- `docker-compose.yml`
- `nginx.conf`
- `data/`

This legacy snapshot is no longer the primary product surface. Older runtime, extension, and embedded UI source trees are not published in this folder.
The main product surface is the VS Code extension in `../vscode-extension`.
